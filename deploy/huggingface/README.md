# AgentHQ

A multi-agent LLM harness you can watch: the boss plans a goal into a DAG,
specialists run the steps in parallel, and a live 2D office shows every agent,
tool call and handoff as it happens.

Source, tests and documentation: https://github.com/Astroash2001/agent-hq

The first page load after the Space has been idle can take a minute while the
container starts.
